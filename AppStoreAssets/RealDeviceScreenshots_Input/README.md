# 真机截图导入与处理指南

如果您希望使用自己 iPhone 真机上的实际阅读截图：

### 1. 在 iPhone 上截取 3～5 张关键画面：
- **截图 1 (主界面)**：打开 PDFview 首页，展示“打开 PDF 或图片”、“大文件 → 重排 → 小屏幕”流程标语与阅读历史。
- **截图 2 (智能大字重排)**：打开一本大文件 PDF，展示重排模式下的大字舒适排版。
- **截图 3 (切边纠偏交互)**：打开一张书籍照片，点击 ✂️ 切边按钮，展示四角拖拽选区。
- **截图 4 (四色纸张/底色)**：展示羊皮纸或豆沙绿护眼底色。
- **截图 5 (竖排古籍/翻译)**：展示古籍竖排重构或离线翻译界面。

### 2. 发送到 Mac
通过 **隔空投送 (AirDrop)** 将这几张截图传到 Mac，存放到本文件夹：
`AppStoreAssets/RealDeviceScreenshots_Input/`

### 3. 一键运行处理脚本
在终端执行：
```bash
python3 scripts/process_real_device_screenshots.py
```
脚本会自动在 `AppStoreAssets/Screenshots_ReadyForUpload/` 下生成：
- **纯真机全屏图**（精准符合苹果 1290x2796 与 1320x2868 规范）
- **专业带文案宣传图**（自动将您的真机截图放入手机外框，上方加上精美中文卖点标语）

直接拖入 App Store Connect 即可上架！
